# Security

This is an early research project without supported releases. Security fixes
apply to the current `main` branch.

While the repository is private, collaborators can report vulnerabilities in its
private issues. Include affected revisions, impact, and reproduction steps;
never include credentials.

Before public launch, enable
[GitHub's private vulnerability reporting](https://github.com/kbak/clafer-lean/security/advisories/new)
and update this policy to direct security reports there. Do not publish sensitive
exploit details in public issues. Ordinary formalization mistakes can be reported
through issue templates.
